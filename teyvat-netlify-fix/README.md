# 提瓦特行旅手册

按 `docs/PRD.md` 与浅色冒险手册样稿实现的原神角色攻略网站。前台、管理后台、API、关系数据库和私有文件存储均为实际实现。部署目标为 **Netlify**；本次按用户要求只交付网站和部署包，不代为上线。

## 先运行网站

需要 Node.js 22.12+（已在 Node.js 24 验证）。在本目录打开终端：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:4173`，点击“初始化站点”，创建你自己的唯一站长账号。**没有内置默认管理员密码。** 可选择添加一份明确标注的功能示例攻略，也可从空白内容开始。

本地使用 PGlite（PostgreSQL 引擎），数据写入 `.data/postgres`，原件与图片写入 `.data/files`。关闭并重新启动后数据仍保留。不要同时启动两个进程访问同一个数据目录。

```powershell
npm test        # 权限、导入、互动、版本、恢复验收
npm run build  # 生成 dist
npm start      # 运行本地生产构建
npm run package # 生成 deliverables/teyvat-netlify-source.zip
```

交付前还通过了 Netlify 离线构建与实际函数 ZIP 运行检查。重新检查函数包时，先运行 `npx netlify-cli build --offline`，再运行 `node scripts/verify-netlify.mjs`；这两步不部署站点。

也可以在 PowerShell 中运行 `./启动网站.ps1`。本地服务只监听当前电脑的 127.0.0.1；正式发布请使用 Netlify。

## 明确边界

1. 未接入外部 OCR / AI 服务。图片与无文字层 PDF 会保留原件并显示明确失败原因，可手动整理；不会冒充自动识别成功。
2. DOCX 提取段落、表格文字和内嵌 PNG/JPEG/WebP。PDF 读取文字层，复杂表格需核对，PDF 内嵌图片需另外上传。
3. 默认单文件 3 MB、PDF 50 页、DOCX 解压总量 25 MB、解析 45 秒超时。UTF-8 文本最多 15 万字符。
4. 内置角色采用经确认样稿的字形视觉，不含第三方角色立绘。初始化时可选的攻略是**功能示例**，不是已验证的最新游戏攻略。
5. 实际游戏攻略内容由管理员导入。当前验收采用人工构造的代表性样本；尚无用户提供的真实攻略文件用于评估识别质量。
6. 云端数据库/存储和独立备份接收端需要你在上线时配置。本次未登录 Netlify、未创建收费资源、未执行云端部署。
