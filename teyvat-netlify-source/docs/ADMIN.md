# 管理员操作手册

## 首次使用

访问 `/setup` 创建唯一站长。本站没有公开默认管理员密码。线上需要部署环境的 `SETUP_KEY`；本地仅监听本机，空站点可直接初始化。普通用户从 `/login` 注册，角色始终由服务端固定为普通用户。

在“账号与权限”创建发布管理员，填写账号、显示名称和初始密码，再自行安全交付账号。管理员可在个人页修改密码。站长停用或变更账号权限后，旧会话立即撤销。唯一站长不能通过用户管理接口删除、降级或停用。

## 导入到发布

1. 管理工作台 → 导入新攻略。选择粘贴文字或上传文件，最大 3 MB。
2. 系统保留原始资料，独立任务提取文字；重复文件会打开已有任务。
3. 检查“完整结构化 / 部分待整理 / 无法识别”结果及提示。解析失败可重试或进入手动整理。
4. 进入可视化整理器。左侧是原文/原图与待归类内容；右侧是方案信息与卡片。仅在文本能唯一匹配角色时预选候选，否则需自己选择。
5. 填写角色、方案名称、适用版本（未知则保留“来源未注明”）、一句话结论与来源署名。至少一张可见有效卡片。
6. 编辑模块类型、标题、内容和来源位置。可用上/下按钮或拖动标记排序，按空行拆分，合并到上一张，隐藏不适用模块。
7. 文档内嵌图片先保存在私有区；明确添加到某张模块后，才随该模块发布。另行上传的展示图片也是同样规则。不要将无关原件设为展示图。
8. 保存草稿 → 预览页面 → 勾选“已核对…” → 直接发布。这里没有站长审核环节。

### 模块填写约定

普通资料无需先改写模板。解析器按常见中文标题识别模块；识别后建议整理为以下形式，使前台卡片更清晰：

```text
武器推荐：
武器名称｜推荐条件、优缺点
另一把武器｜替代条件

词条选择：
时之沙：元素精通
空之杯：来源提供的主词条
理之冠：来源提供的主词条

配队方案：
角色一｜职责
角色二｜职责
角色三｜职责
角色四｜职责
替代与说明：来源给出的替代人选及条件

操作循环：
角色一：第一步说明
角色二：第二步说明

培养路线：
准备指定突破材料
确认武器等级
```

每行一项。武器最多选择三项对比；配队前四行形成四个位置，后续行展开说明；循环按顺序显示，不虚构时长。不要在没有来源支持的情况下填写精确百分比、充能目标或伤害提升。

## 更新与下架

- 发布管理员：可创建、整理、删除自己的未发布草稿，首次发布后只能查看记录；无法修改/下架/删除已发布内容。
- 站长：可编辑全部方案。编辑已发布方案时写入独立草稿；保存不会影响公开内容。再次“更新发布”才原子切换新版本。
- 新版本评分重新统计，旧评分保留。点赞绑定方案，更新后保留。评论记录发言时的版本。
- 下架会让公开方案返回 404，停止新增互动；无其他公开版本引用的展示图片也变为私有。角色是否公开单独控制。
- 同一草稿在两个窗口编辑时，过期修订保存会提示冲突，不会覆盖新内容。请记录当前修改、重新载入再整合。
- 同名方案会提示，不会覆盖其他方案。默认方案由站长在角色目录选择；未选择则使用最早发布且仍有效的方案。

## 互动处置

“评论与举报”查看最近评论与举报。站长可以隐藏或恢复未删除评论，并将举报标记为已处理。用户只能删除自己的评论；有回复时保留删除占位。停用账号会撤销全部会话，其既有攻略与评论不会自动消失，可由站长逐项处置。

## 导入边界

- 原始资料不允许游客下载。只有站长或文件所属发布管理员可以查看。
- 图片/扫描 PDF 当前没有 OCR 服务，明确报错并保留原件，不会上传到未知第三方。
- DOCX 表格文字可以提取，但不保证复杂合并单元格关系；PDF 多栏和表格需要对照原件校正。
- 原文件中任何脚本、HTML 都不会在公开页面执行。文本作为普通文字渲染。
- 无法识别的段落保留在待整理区；不要把“解析成功”等同于“内容正确”。
